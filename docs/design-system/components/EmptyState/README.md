# EmptyState

What a screen shows when there is nothing to show — never a dead end.

Every empty state does three things: **name the situation, explain it in one line, offer the single most useful next action.**

**The zero-result case is the important one.** Property searches are over-constrained constantly, so the empty search state does real work: it names the most restrictive filter, offers to relax it, and shows what *is* nearby. A blank "No results" screen sends the user to a competitor.

**Relaxation is always disclosed** with one-tap undo. A silently widened search feels like a broken filter.

| Screen | Action offered |
|---|---|
| Search, no results | Remove the blocking filter · widen radius · save the search |
| Saved properties | "Browse flats in Kolkata" |
| My listings | "Post your property — it's free" (`supply-600`) |
| Lead inbox | Explain what improves visibility |
| Admin queue | Plain confirmation — no action needed |

**Consumer provides**: the reason it is empty and the relevant recovery action.
