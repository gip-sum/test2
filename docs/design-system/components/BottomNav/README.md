# BottomNav

Primary navigation on phones, where the majority of this product's traffic will be.

A bottom bar is the right pattern here because the audience is mobile-majority and expects app conventions on mobile web.

**Five destinations, fixed**: Search · Saved · **Post** · Enquiries · Account.

**Rules**

- **Post sits in the centre and is visually distinct** (`supply-600`), because supply is the scarce side of the marketplace.
- Minimum 44×44 targets; padding adds `env(safe-area-inset-bottom)`.
- **Hidden inside the posting wizard and the gallery lightbox** — those are focused tasks, and on the property page the sticky contact bar takes its place.
- Active state is icon + label + colour, never colour alone.
- Badge counts appear on Enquiries when there are unread leads.

**Consumer provides**: the current route and unread counts.
