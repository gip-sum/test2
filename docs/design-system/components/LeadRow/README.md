# LeadRow

One enquiry in the seller's inbox — where the entire perceived value of the platform lives.

If a seller ever logs in and this screen is unclear, the product has failed them.

**Two lead types, visually distinguished**

- **Enquiry** — the buyer sent a message.
- **Viewed contact** — the buyer verified their number and revealed the seller's. Higher intent.

**Every row shows**: buyer name, verified phone, the property, when it arrived, and the lead type. The seller can set a status (New → Contacted → Qualified → Closed / Lost) and add a note. That is a working tool, not a list — and it is what brings sellers back.

**Rules**

- New leads are visually distinct until opened; response speed is the strongest driver of conversion.
- The phone number is tappable (`tel:`) and copyable in one action.
- Repeat reveals by the same person on the same listing collapse into one row — a seller must never think they received two leads when they received one.
- Sort is newest-first and cannot be overridden into something confusing.

**Consumer provides**: the lead list and status-change handlers.
